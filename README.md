# 点心去玩

**团队名：** 赛博点心局
**参赛赛道：** Redesign（重新发明）

## 项目介绍
常规App解决怎么走，点心去玩解决怎么伴。一个集AI情绪陪伴、智能行程规划、多人协同于一体的旅行工作台。核心AI旅伴“点点”能识别用户情绪（疲惫/迷路/烦躁等），并真的动手修改行程列表，而不只是聊天。

## 核心功能
1. AI地理盲盒：输入位置和心情，生成不走回头路的小众秘境路线。
2. AI情绪伴侣“点点”：识别情绪，先共情，再修改行程。
3. 意图路由层：区分P0紧急需求（找厕所/医院）、P1闲聊、P2常规需求。
4. 一键AI优化：按时间段重排行程，餐厅放中午，夜景放晚上。
5. 记账AA与好友邀请。

## 如何运行
1. 下载本仓库所有文件到本地文件夹。
2. 双击 `index.html`，即可在浏览器中打开。
3. 无需安装任何环境，断网也能完美运行。

## 技术路径
纯前端单文件（HTML+Tailwind CSS内联+原生JS），内联SVG图标，本地localStorage存储，接入GLM大模型（带本地兜底防断网）。
